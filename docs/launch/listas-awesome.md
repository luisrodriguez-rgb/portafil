Título del PR: `Add Perfila to Tools`

Pieces are SVG with CSS animation only, so they render in a README, and the web builder outputs `<picture>` blocks for light and dark mode.

```markdown
- Web: https://DOMINIO
- Example profile: https://github.com/OWNER/REPO/tree/main/examples
```
